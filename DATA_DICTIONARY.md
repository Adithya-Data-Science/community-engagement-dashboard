# Data dictionary

| Field | Meaning |
| --- | --- |
| `Partnership_ID` | Unique identifier for a partnership record |
| `University_Department` | University unit associated with the activity |
| `Community_Partner` | Synthetic partner organization name |
| `Partnership_Type` | Program or collaboration category |
| `Engagement_Activity` | Primary activity delivered by the partnership |
| `Impact_Area` | Intended area of community impact |
| `Project_Start_Date` | Activity start date |
| `Project_End_Date` | Activity end date |
| `Participants_Engaged` | Number of participants reached |
| `Student_Volunteers` | Number of participating student volunteers |
| `Funding_Amount_USD` | Funding associated with the record, in U.S. dollars |
| `Community_Satisfaction_Score` | Satisfaction score on a five-point scale |
